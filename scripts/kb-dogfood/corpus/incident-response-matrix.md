# Incident Response Matrix

This matrix grades incidents and sets the response. It is referenced by the
[[field-operations-sop]] and the [[post-orders-bluebay]].

## 1. Severity Grades

- **Code Green** — routine. Log in the Daily Occurrence Book; no escalation.
- **Code Amber** — significant (trespass, minor injury, equipment failure).
  Notify the duty manager within the shift.
- **Code Red** — critical (threat to life, armed intrusion, major loss or fire).
  Follow the Code Red timeline in the [[field-operations-sop]].

## 2. Medical Emergency Call Order

A medical emergency is graded Code Amber unless life is at risk, when it is Code
Red. The call order is fixed and must be followed in sequence:

1. **First** — the on-site trained first aider (collar number on the shift board),
   who attends with the defibrillator while the call order continues.
2. **Second** — dial 999 for the ambulance.
3. **Third** — the control room, which logs the event and dispatches the mobile
   patrol to guide the ambulance in.
4. **Fourth** — the duty manager, who notifies the client.

Do not call the duty manager before the ambulance; the sequence exists so that
clinical help is moving before anyone is notified up the chain.

## 3. Common Incident Types

- Fire alarm: evacuate to the muster point, never re-enter, grade Code Amber or Red.
- Intruder on site: observe and report, do not confront, grade per threat.
- Lost child in the retail park: contact store management and control, grade Amber.
- Power failure: check that emergency lighting and the CCTV UPS are live, grade Amber.

## 4. Reporting

Every graded incident produces a Daily Occurrence Book entry; Amber and Red also
produce a written incident report within 12 hours.
