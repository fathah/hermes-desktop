# Key Control Policy

## 1. Storage

Spare keys for every assignment are held in a locked steel cabinet in the control
room. The cabinet combination is known only to duty supervisors and is changed
each quarter, and whenever a supervisor leaves. A signed key register records every
issue and return.

## 2. Issue and Return

A key is issued against signature at the start of a shift and returned at the end.
A key that is not returned is reported immediately and the affected locks are
re-suited at the contractor's cost if negligence is found. Master keys never leave
the assignment.

## 3. Lost Keys

A lost key is treated as a security incident, logged in the Daily Occurrence Book,
and escalated to the Operations Director. Where a lost key compromises a client
site, the locks are changed within 24 hours.
