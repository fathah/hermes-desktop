# Hermes Desktop v0.7.9

Hermes Desktop v0.7.9 gives the reviewed v0.7.8 application a fresh stable version as the release branch catches up with main.

## Scope

This patch changes release metadata only; application code, runtime assets and dependency versions match v0.7.8.

The release retains Agent v0.23.1 compatibility, managed runtime discovery, the canonical Windows interpreter fix, Electron 44.9.1 and the Linux arm64 updater feed. See the [v0.7.8 release notes](v0.7.8.md) for the full feature and compatibility details.

## Version and tag identity

The manifest and both lockfile version fields agree on `0.7.9`, while existing published tags remain unchanged.

The release workflow builds all configured platforms and winget manifests before creating `v0.7.9`. Creating that tag manually beforehand would cause its existing-tag check to skip the build and publication jobs. CI quality checks must pass before promoting the reviewed version to the release branch.

## Validation boundaries

The [v0.7.8 acceptance record](../compatibility-acceptance-2026-11-12.md) identifies earlier native installer, updater and real Agent chat results; it is historical evidence rather than a v0.7.9 test result.

Fresh source checks and the release workflow validate this version's builds. Desktop and Agent continue to update independently; this metadata patch does not require reinstalling Agent or changing Remote hosts.
